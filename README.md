# End-to-End Machine Learning Operations (MLOps) with Azure Machine Learning

![mlops-header-1](/media/mlopsheader.jpg)

**Machine learning operations (MLOps)** applies DevOps principles to machine learning projects. Specifically, it is a set of repeatable, automated, and collaborative workflows with best practices that empower teams of ML professionals to quickly and easily get their machine learning models deployed into production.

![mlops-header-2](/media/mlops-in-a-box.webp)

## Prerequisites

1. Programming experience with Python or R
2. Experience developing and training machine learning models
3. Familiarity with basic Azure Machine Learning concepts
